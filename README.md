# PPT 字体统一替换工具

一个 Windows 桌面小工具：选择一个 .pptx 文件和一套字体，一键把 PPT 中所有文本框的文字（含母版、版式、备注页、表格）统一替换为目标字体。**不处理图片**，图片中的文字不受影响。

## 功能特点

- 同时设置 Latin / 东亚（中文）/ 复杂文种三种字体属性，中英文都生效
- 支持文本框、占位符、组合图形、表格单元格、备注页、母版/版式背景文字
- 字体来源两种方式：
  1. 把整套字体（.ttf/.otf/.ttc）放入程序同目录的 `fonts` 文件夹，启动自动加载
  2. 运行时在界面中手动选择字体文件
- 输出文件命名为 `原文件名_统一字体.pptx`，不覆盖原文件

## GitHub 自动构建（推荐）

1. 把本仓库推送到 GitHub
2. 进入 **Actions** 页面，运行 **Build Windows EXE** 工作流
3. 构建完成后，在 **Artifacts** 中下载 `PPTFontReplacer-exe`

打 tag（如 `v1.0`）推送后，会自动创建 Release 并附上 exe。

## 使用说明

1. 打开程序
2. 点击「浏览…」选择要处理的 .pptx 文件
3. 选择字体文件（或已自动加载 fonts 目录中的字体）
4. 点击「开始统一替换字体」
5. 在原 PPT 同目录下得到 `xxx_统一字体.pptx`

## 注意事项

- 只支持 .pptx 格式；.ppt 请先用 PowerPoint 另存为 .pptx
- 替换的是字体引用，目标字体需在打开 PPT 的电脑上安装才能正确显示
- 若字体识别名与预期不符，可尝试把字体文件重命名为其真实字体名
